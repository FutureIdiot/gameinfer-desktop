# GameInfer Desktop v0.1.0

[English](#english) | [简体中文](#简体中文)

## English

The first pinned GameInfer Desktop release, based on a Windows package validated on a physical PC.

### Included

- Portable Windows x64 `GameInfer.exe`
- GAME 1.0.3 small ONNX MIDI model
- Persistent vocal-separation worker with a managed `uv` runtime
- DirectML GPU support; the GPU option is disabled when the environment does not support it
- Vocals output by default, with optional Vocals + Instrumental retention; only Vocals continue to MIDI conversion

### Usage

Extract the complete ZIP and run `GameInfer.exe`; do not move the executable out of its directory. On the first separation run, GameInfer installs its locked dependencies and downloads the selected separation model. Keep the PC online and allow additional setup time. Later runs reuse the cache.

This package is not code-signed. Windows may display a SmartScreen warning.

### Known limitation

If separated vocals still contain a segment that cannot be automatically sliced below 60 seconds, conversion fails in this version. The manual waveform-cropping feature added later is not included in this initial release.

## 简体中文

GameInfer Desktop 的首个固定版本，基于已在 Windows 实体 PC 上验证的软件包。

### 包含内容

- Windows x64 便携版 `GameInfer.exe`
- GAME 1.0.3 small ONNX MIDI 模型
- 人声分离常驻 worker 与 `uv` 托管运行时
- DirectML GPU 支持；环境不支持时界面会禁用 GPU 选项
- 默认输出 Vocals，也可以同时保留 Vocals + Instrumental；只有 Vocals 会继续进入 MIDI 转换

### 使用说明

请完整解压 ZIP 后运行 `GameInfer.exe`，不要将 EXE 单独移出原目录。首次执行人声分离时，GameInfer 会自动安装锁定版本的依赖并下载所选分离模型，请保持电脑联网并预留额外等待时间；后续运行会复用缓存。

本软件包未进行代码签名，Windows 可能显示 SmartScreen 提示。

### 已知限制

如果分离后仍出现无法自动切到 60 秒以内的连续音频片段，本版本会转换失败；后续新增的手动波形裁切尚未包含在此初版中。
