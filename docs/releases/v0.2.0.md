# GameInfer Desktop v0.2.0

[English](#english) | [简体中文](#简体中文)

## English

This release completes the first standalone cross-platform GameInfer Desktop workflow and adds manual recovery for audio that still cannot be sliced below 60 seconds after vocal separation.

### Highlights

- Adds a waveform player and movable cut position for failed overlong slices
- Replaces the failed queue item with two shorter MIDI tasks after confirmation
- Adds configurable workspaces for separated audio and manual slices
- Cleans successful intermediate files automatically, with an option to retain them and a button to clear old workspace files
- Bundles the GAME 1.0.3 small ONNX model and the default `Kim_Vocal_2.onnx` separation model
- Shows separator environment/model installation status in the application status area
- Provides Windows x64 with DirectML and macOS arm64 packages from the same source revision

### Usage

Extract the complete archive and keep its directory structure intact. On the first separation run, GameInfer prepares its locked separator environment. Both packages include the default separation model; selecting another compatible model may require an additional download.

### Notes

- The Windows package is not code-signed and may display a SmartScreen warning.
- The macOS package is ad-hoc signed but not notarized; Gatekeeper may require explicit approval on first launch.
- Only the vocal output continues to MIDI conversion. The optional instrumental output is retained as an intermediate result when selected.

## 简体中文

此版本完成了首个独立的跨平台 GameInfer Desktop 工作流，并为人声分离后仍无法切到 60 秒以内的音频增加了手动恢复方式。

### 主要更新

- 为失败的超长切片增加波形播放器和可拖动的裁切位置
- 确认裁切后，以两个更短的 MIDI 任务替换原失败任务
- 增加可配置的分离音频与手动切片工作区
- 任务成功后自动清理中间产物，同时支持保留中间产物以及一键清理旧工作区文件
- 内置 GAME 1.0.3 small ONNX 模型和默认的 `Kim_Vocal_2.onnx` 分离模型
- 在应用底部状态区域显示分离环境及模型安装状态
- 从同一个源码提交提供 Windows x64 DirectML 包与 macOS arm64 包

### 使用说明

请完整解压软件包并保持目录结构不变。首次执行人声分离时，GameInfer 会准备锁定版本的分离运行环境。两个平台包都已内置默认分离模型；如果选择其他兼容模型，可能仍需额外下载。

### 注意事项

- Windows 软件包未进行代码签名，系统可能显示 SmartScreen 提示。
- macOS 软件包使用临时签名但未经过 Apple 公证，首次启动时可能需要在系统中明确允许。
- 只有人声输出会继续进入 MIDI 转换；选择保留伴奏时，伴奏只作为中间产物保存。
